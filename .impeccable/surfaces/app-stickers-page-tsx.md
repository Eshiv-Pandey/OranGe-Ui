# Sticker gallery, editor and placement playground

Mode: Experience for the collection; Operate for editing and placement. This is an extension of the existing neutral library workspace.

## Direction contract

The owner requested keeping the first fifty cartoon-like designs, introducing sharper finishes and commonly useful motifs, replacing the rejected peel animation, adding npm distribution, and building a sticker placement playground. The pack now has seventy designs and two finishes. Preserve the incumbent design system and the liked right-side preview.

FIRST VIEWPORT: a compact introduction and small original sticker fan leave room for complete catalogue cards. There is one Playground launcher. Search and categories live beside the compact right inspector, whose export actions fit the desktop viewport. The default collection starts with Everyday designs. Phones show the collection first and expand the inspector on selection. Keep neutral surfaces, consistent controls and original artwork.

Signature interaction: click, Enter or Space presses the sticker then lets it spring and settle. Alternate wiggle, spin and no-motion choices are explicit. The complete artwork remains visible during hover; there is no diagonal clipping or fold. Reduced motion overrides animation.

Editor: a compact native modal with a rotation-safe preview, a real color picker and palette presets. Appearance/Motion tabs expose size, rotation, finish, animation, duration, intensity and shadow without internal scrolling. Copy/download actions replace long code panes and reflect every component setting. Native Escape, focus confinement and focus restoration are required. The gallery inspector shares the same compact controls.

Playground: a full-window native workspace with a large canvas and right sidebar on desktop, stacked tools on phones. Short Stickers/Edit/Layers/Canvas panes keep the workspace usable. Allow placement on and beyond canvas edges; deliberate crop must match exported React/HTML/JSON. A visible X removes the selected sticker, even when its artwork is partly outside the canvas. Layers drag to reorder; the top list item paints in front. Pointer grips and keyboard forward/back buttons both work. Preserve per-placement settings, undo, duplicate, keyboard movement, empty states and the eighty-item limit. Custom colors and palette presets survive exports; caption contrast follows background luminance. No dependency is required by standalone HTML.

Package: orangeui-stickers contains all seventy components, ESM/CommonJS, types and standalone CSS, with React peer dependencies and no site/font dependencies. Registry installation of orangeui-stickers@0.1.0 is verified. The public versioned tarball remains an alternative npm install target.
