# Sticker gallery, editor and placement playground

Mode: Experience for the collection; Operate for editing and placement. This is an extension of the existing neutral library workspace.

## Direction contract

The owner requested keeping the established cartoon-like collection, introducing sharper finishes and commonly useful motifs, replacing the rejected peel animation, adding npm distribution, and building a sticker placement playground. The pack has seventy designs and two finishes. The fourth refinement redraws the requested hand, pencil, moon, comet, satellite, sun, cube, flag, pinwheel, music note and ribbon motifs while preserving their names and API. Both finishes share precise painted silhouettes, black contours and die-cut paper margins with no artwork spill or export-edge clipping. Preserve the incumbent design system and the liked right-side preview.

FIRST VIEWPORT: a compact introduction and small original sticker fan leave room for complete catalogue cards. There is one Playground launcher. Search and categories live beside the compact right inspector, whose export actions fit the desktop viewport. The default collection starts with Everyday designs. Phones show the collection first and expand the inspector on selection. Keep neutral surfaces, consistent controls and original artwork.

Signature interaction: hover or keyboard focus raises the sticker and gives it a short wiggle; click, Enter or Space plays the chosen bounce, wiggle, spin or no-motion response. Static artwork can opt into hover motion with the legacy hoverPeel prop. The complete die-cut artwork remains visible, with painted details contained by its silhouette. Reduced motion overrides all movement, and touch-only devices disable hover movement.

Editor: a compact native modal with a rotation-safe preview, a labelled Custom color control that opens the real color picker, and palette presets. Appearance/Motion tabs expose size, rotation, finish, animation, duration, intensity and shadow without internal scrolling. Native selects show a consistent chevron with reserved text space. Copy/download actions replace long code panes and reflect every component setting. Native Escape, focus confinement and focus restoration are required. The gallery inspector shares the same compact controls.

Playground: a full-window native workspace with a measured canvas that fills available space and a narrower right sidebar on desktop, stacked tools on phones. Short Stickers/Edit/Layers/Canvas panes keep the workspace usable. The denser three-column sticker tray measures its height and paginates up to thirty items. Allow placement on and beyond canvas edges; deliberate crop must match exported React/HTML/JSON. A visible X removes the selected sticker, even when its artwork is partly outside the canvas. Layers drag to reorder; the top list item paints in front. Pointer grips and keyboard forward/back buttons both work. Preserve per-placement settings, undo, duplicate, keyboard movement, empty states and the eighty-item limit. Custom colors and palette presets survive exports; caption contrast follows background luminance. No dependency is required by standalone HTML.

Preview: a dedicated Preview action requests browser fullscreen and falls back to the same clean window-filling view if unavailable or denied. Hide editing chrome, selection outlines, removal controls and empty-state editing prompts. Disable drag, keyboard placement and deletion while keeping sticker activation available. Back to editor and Escape restore the unchanged arrangement and focus on Preview. The design survives leaving Preview and closing/reopening the workspace.

Package: orangeui-stickers contains all seventy components, ESM/CommonJS, types, contours and standalone CSS, with React peer dependencies and no site/font dependencies. orangeui-stickers@0.1.1 is published publicly as npm latest. Isolated local and registry installation, all seventy designs in both finishes, React/CSS bundling and Bundler/NodeNext declarations are verified, with matching exact local/registry SHA-512 integrity. The earlier 0.1.0 registry installation remains historical evidence. The local public versioned tarball is an alternative npm install target.

Build, TypeScript, twenty-four focused unit tests, six browser tests, scoped ESLint, copy and whitespace checks passed.
