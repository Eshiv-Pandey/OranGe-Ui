# Sticker gallery, editor and placement playground

Mode: Experience for the collection; Operate for editing and placement. This is an extension of the existing neutral library workspace.

## Direction contract

The owner requested keeping the established cartoon-like collection, introducing sharper finishes and commonly useful motifs, replacing the rejected peel animation, adding npm distribution, and building a sticker placement playground. The pack has seventy designs and two finishes. The fifth refinement improves recognition of Peace hand, Moka morning, Pocket play, Comet tail, Bubble tea, Infinity ribbon and Link knot while preserving their names and API. Both finishes share precise painted silhouettes, black contours and die-cut paper margins with no artwork spill or export-edge clipping. Preserve the incumbent design system and the liked right-side preview.

FIRST VIEWPORT: a compact introduction and small original sticker fan leave room for complete catalogue cards. There is one Playground launcher. Search and categories live beside the compact right inspector, whose export actions fit the desktop viewport. The default collection starts with Everyday designs. Phones show the collection first and expand the inspector on selection. Keep neutral surfaces, consistent controls and original artwork.

Signature interaction: hover or keyboard focus raises the sticker with a more pronounced short wiggle and soft elevated shadow when shadow is enabled; click, Enter or Space plays the chosen bounce, wiggle, spin or no-motion response. Static artwork can opt into hover motion with the legacy hoverPeel prop. The complete die-cut artwork remains visible, with painted details contained by its silhouette. Reduced motion overrides all movement, and touch-only devices disable hover movement. Search fields share one continuous focus border around their whole field, with no nested input outline.

Editor: a compact native modal with a rotation-safe preview, a labelled Custom color control that opens the real color picker, and palette presets. Appearance/Motion tabs expose size, rotation, finish, animation, duration, intensity and shadow without internal scrolling. Native selects show a consistent chevron with reserved text space. Copy/download actions replace long code panes and reflect every component setting. Native Escape, focus confinement and focus restoration are required. The gallery inspector shares the same compact controls.

Playground: a full-window native workspace with a measured canvas that fills available space and a narrower right sidebar on desktop, stacked tools on phones. Short Stickers/Edit/Layers/Canvas panes keep the workspace usable. The denser three-column sticker tray measures its height and paginates up to thirty items. Allow placement on and beyond canvas edges; deliberate crop must match exported React/HTML/JSON. A visible X removes the selected sticker, even when its artwork is partly outside the canvas. Layers drag to reorder; the top list item paints in front. Pointer grips and keyboard forward/back buttons both work. Preserve per-placement settings, undo, duplicate, keyboard movement, empty states and the eighty-item limit. Custom colors and palette presets survive exports; caption contrast follows background luminance. No dependency is required by standalone HTML.

Preview: a dedicated Preview action requests browser fullscreen and falls back to the same clean window-filling view if unavailable or denied. The canvas fills the entire viewport without letterbox bars. Normalized placement anchors follow its responsive width and height while SVG artwork remains square. Hide editing chrome, selection outlines, removal controls and empty-state editing prompts. Existing stickers support drag and keyboard movement; deletion stays protected. Completed drags persist and create one undo step; interrupted drags roll back. Back to editor and Escape return focus to Preview. The design survives leaving Preview and closing/reopening the workspace. React and standalone HTML exports follow this viewport layout; React accepts a height prop for embedding. Logical 960x600 units still define sticker sizes in JSON. React/HTML/JSON are visible themed format choices with keyboard navigation, not an unstyled native popup.

Package: orangeui-stickers contains all seventy components, ESM/CommonJS, types, contours and standalone CSS, with React peer dependencies and no site/font dependencies. Version0.1.2 is published publicly as npm latest and downloadable from the gallery. Isolated local and registry installation passed all seventy designs in both finishes, React/CSS bundling and Bundler/NodeNext declarations, with exact matching registry/tarball SHA-512 integrity. The 0.1.0 and 0.1.1 public releases remain historical evidence.

Finish record: the fresh reviewer returned ship at the v5 refinement scope with no material fixes after inspecting five contact sheets covering 120 valid captures, the seven artwork pairs and primary source samples. Build, TypeScript, twenty-six focused unit tests and all seven final browser checks passed, with zero scanned accessibility violations. Three initial browser failures were corrected in tests only: raw CSS formatting after correct undo and a hover target outside the first tray page. No application edits or extra captures followed. Scoped ESLint, copy and whitespace checks passed. The documenter preserved the incumbent system. See `.impeccable/review/stickers-v5/final-review.md` for evidence and limits.
