# Blocks collection

Scope: an extension of the existing oRangeUi library, covering original reusable page sections and their source-installation workflow. Visitor mode: Read for discovery and Operate for previewing and copying.

## Direction contract

THESIS: useful page sections become a coherent extension of the library. Every category leads to a real preview and installable source, with few considered examples rather than a wall of variants.

OWN-WORLD: inherit Geist, the orange pixel identity, semantic orange actions, neutral surfaces, readable borders and the polished control family. Original section compositions use generous type, real licensed photographs and precise small interactions.

STORY: choose a section, inspect it at desktop or phone width, try its behavior and bring its complete source into a project. Data and provider callbacks stay application-owned.

FIRST VIEWPORT: the existing library rail and compact header frame a direct Blocks heading, concise introduction, visible search and category filter, and large preview thumbnails. Opening cards show the original auth and hero work at useful scale.

FORM: established-library extension; code-led. No concept tournament is needed because the owner pinned the existing system and asked for the same section capabilities. Signature interaction: live width switching preserves the preview's real layout and form state.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
