# Paper Cut

Scope: one reusable visual component in the established library. Mode: Experience for the artwork, Operate for the live editor.

## Direction contract

THESIS: soft organic cut-paper contours become a tactile, cursor-responsive banner surface. Shape, depth and useful interaction carry the composition.

OWN-WORLD: the supplied blue paper-cut reference pins the artwork's ocean palette, rounded flowing edges, layered shadows and white negative space. Original generated paths and optional citrus/graphite palettes belong to this component; the library keeps Geist and its existing neutral controls.

STORY: inspect the material, move the pointer to feel individual sheets shift, adjust the palette and depth, then install portable source. Pointer leave gently centers the stack; keyboard users can explore with arrow keys.

FIRST VIEWPORT: a generous, fully visible paper landscape fills the working preview. The established inspector exposes palette, sheet count, depth and interaction strength. The catalogue shows a still of the same original geometry.

FORM: code-led extension with a pinned reference material. Signature interaction: depth-weighted sheet parallax eases toward the cursor and stops drawing when settled; touch preserves vertical page scrolling.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
