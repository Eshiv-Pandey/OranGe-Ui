# Endless Film display font

FilmCormorant is a local CSS alias for Cormorant Garamond, italic, weight 500. The Latin WOFF2 subset is served locally under the SIL Open Font License 1.1. Keep OFL-cormorant-garamond.txt with redistributed copies.

Font source, retrieved November 9, 2026:
