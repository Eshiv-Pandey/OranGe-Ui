# Bento collection

Five new original layouts precede Everything in its place: Wildseed, Current, Folio, Sidequest and Nightshift.

Wildseed uses a green and violet ecological mosaic. Current uses a dense commerce collage, original mobile product screen and licensed editorial photography. Folio uses a lavender dashboard with a revenue period control that changes the chart, users, growth and totals together. Sidequest uses playful studio project windows and original illustrations. Nightshift uses the existing orange glass tube sign, mint outlines and cream on black.

All branding, links and primary content are configurable. Folio accepts complete period datasets and an empty dataset. Sidequest accepts project data and an empty list. Nightshift accepts opening hours, sign text, a photograph and a flicker toggle. All sign sound is off; flicker respects visibility and reduced motion. Both library palettes retain each composition's intended material.

The Pinterest references supplied by the owner were inspected through Pinterest's public pin image endpoint. They guided composition and material; reference pixels, brands, slogans and characters are not shipped. Original oRangeUi illustrations and licensed photographs are included with their notices. The display fonts are locally hosted OFL fonts under public/fonts/sections/.

Source ZIPs and registry installs include all required CSS, dependencies, fonts and illustrations. Registry source embeds local art and fonts as data URLs. Native links remain application-owned; demonstration data is fictional.

Verification uses the production build, standalone source compilation, keyboard interaction and a 320/390/768/1440 width matrix in both palettes. Local evidence is under out/section-expansion/.
